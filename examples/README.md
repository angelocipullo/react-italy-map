# Examples

Each file is a self-contained React component using `react-italy-map`, as running in the [live demo](https://angelocipullo.github.io/react-italy-map/). Sample data lives in [`data/`](data/) and is approximate.

The `ex-*` class names come from the demo stylesheet ([`demo/App.css`](../demo/App.css)) and only handle layout — drop them or use your own.

Run them locally with `npm run dev`. This folder is not part of the npm package.
